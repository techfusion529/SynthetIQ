# SynthetIQ Quick Start

Get SynthetIQ running with real AI in under 10 minutes.

## Prerequisites Check

```bash
# Check Python version (need 3.13+)
python --version

# Check Node.js (need 18+)
node --version

# Check Docker
docker --version
```

## 1. Get Gemini API Key (2 minutes)

1. Visit: https://aistudio.google.com/app/apikey
2. Click "Create API Key"
3. Copy the key (starts with `AIzaSy...`)

## 2. Configure Environment (1 minute)

```bash
# Copy template
cp .env.example .env

# Edit .env and add your Gemini API key
# Windows:
notepad .env

# Mac/Linux:
nano .env
```

Add this line:
```env
GEMINI_API_KEY=AIzaSy...YOUR_KEY_HERE
```

## 3. Install Dependencies (2 minutes)

```bash
# Install uv (Python package manager)
# Windows (PowerShell):
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# Mac/Linux:
curl -LsSf https://astral.sh/uv/install.sh | sh

# Install Python dependencies
uv pip install -e "worker[dev]"
uv pip install -e "api[dev]"

# Install dashboard dependencies
cd dashboard
npm install
cd ..
```

## 4. Start Infrastructure (1 minute)

```bash
# Start Temporal, Redis, Prometheus, Grafana
docker compose -f deploy/docker-compose.yml up -d

# Verify services are running
docker compose -f deploy/docker-compose.yml ps
```

Expected output:
```
NAME                     STATUS
temporal                 Up
temporal-ui              Up
redis                    Up
prometheus               Up
grafana                  Up
```

## 5. Start Worker (1 minute)

Open a new terminal:

```bash
cd worker
python -m src.main
```

You should see:
```
INFO: Initialized GeminiAIService with model=gemini-2.0-flash-exp
INFO: Initialized JevSystem1Auditor in HYBRID_ENSEMBLE mode
============================================================
🚀 SynthetIQ Temporal Worker Started Successfully!
============================================================
```

## 6. Start API (1 minute)

Open another terminal:

```bash
cd api
uvicorn src.main:app --reload --port 8000
```

In a new terminal:

## Troubleshooting

### "GEMINI_API_KEY is required"
- Check `.env` file exists and has your API key
- Restart the worker after adding the key

### "Connection refused" to Temporal
```bash
# Restart Docker services
docker compose -f deploy/docker-compose.yml restart

# Check logs
docker compose -f deploy/docker-compose.yml logs temporal
```

### "Module not found" errors
```bash
# Reinstall dependencies
cd worker
uv pip install -e .
```

### Workflow shows errors
- Check worker logs for details
- View in Temporal UI: http://localhost:8080
- Check Gemini API quota: https://aistudio.google.com/app/apikey
